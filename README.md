# Project Overview
 
This project is a fundamental Android application designed to showcase a standard User Authentication Flow. It is built as a learning tool to master the Android Activity Lifecycle and Material UI design principles. The app features a professional-looking interface with a focus on usability and secure navigation.


# Tech Stack


1. Language: Java (used for backend logic and navigation).


2. UI/Design: XML (used for defining layouts and custom styles).


3. Framework: Android SDK (supporting API 24 and above).

  
4. Design Library: Google Material Design 3 (used for modern components like MaterialCardView).


5. Architecture: Logic-UI Separation (Clean separation between Java controllers and XML layouts).


# Key Features


1. User Authentication: A functional login system that validates user inputs against hardcoded credentials.



2.Account Registration: A dedicated Sign-Up screen for new users to create accounts.



3. Explicit Navigation: Smooth transitions between screens using the Android Intent system.


4. Session Security: Uses Activity Stack Management (finish()) to ensure that once a user logs in, they cannot navigate back to the login screen without logging out.


5. Custom UI Styling: Hand-crafted XML drawables for rounded-corner inputs and branded purple/white theme consistency.
